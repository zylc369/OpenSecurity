# Security Analysis 系统新机器配置指南

> 从零在一台新机器上配置 Security Analysis 系统（含 binary / web / mobile / AI / crypto 全部 Agent）。
> 各 Agent **共用同一个 Python 虚拟环境**（`~/bw-security-analysis/.venv`），按需安装对应工具：IDA→binary，apktool/jadx→mobile，SageMath→crypto。

## 前置条件

- IDA Pro 已安装（需要 `idat` 可执行文件）
- Miniforge 已安装（提供 conda + Python）
  - macOS: `curl -L -O https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-MacOSX-$(uname -m).sh && bash Miniforge3-MacOSX-$(uname -m).sh`
  - Linux/Windows: 参考 https://conda-forge.org/download
- Git 已安装
- OpenCode (opencode CLI) 已安装

## 步骤

### 1. 克隆项目

```bash
git clone <仓库地址>
cd open-security
git submodule update --init --recursive
```

> `vendor/oh-my-openagent` 是子模块，必须用 `--recursive` 初始化。

### 2. Python 依赖

首次对话时 Plugin 会检测依赖完整性，缺失时提示运行安装脚本。

### 3. 安装 C/C++ 编译器

| 平台 | 安装命令 |
|------|---------|
| Windows | 下载 [VS Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)，安装时勾选"使用 C++ 的桌面开发" |
| Linux | `sudo apt install build-essential libgmp-dev` |
| macOS | `xcode-select --install` |

### 4. 配置 IDA Pro 路径

控制台首次启动时检查 `$OPENCODE_ROOT/.ai_env`，文件不存在时创建模板（创建后不再重写）。填入 IDA 安装目录（含 idat）：

```ini
# $OPENCODE_ROOT/.ai_env
IDA_PRO_HOME=<IDA Pro 安装目录>
```

**IDA_PRO_HOME 示例**:
- Windows: `C:\Program Files\IDA Pro 9.0`
- Linux: `/opt/ida-9.0`
- macOS: `/Applications/IDA Professional 9.1.app/Contents/MacOS`

> 也可在控制台配置页设置 `IDA_PRO_HOME`。其他外部工具靠 PATH 检测。

### 5. 在 OpenCode 中使用

1. 启动 OpenCode: 在项目根目录运行 `opencode`
2. 按 `Tab` 键切换 Agent
3. 选择 `binary-analysis`
4. 输入分析需求（如: `/path/to/target.exe 分析这个文件的加密算法`）

如果没报错，意味着初始化成功，否则按照错误提示处理。

## 常见问题

| 问题 | 解决方案 |
|------|---------|
| conda 未安装 | 安装 Miniforge: macOS `curl -L -O https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-MacOSX-$(uname -m).sh && bash Miniforge3-MacOSX-$(uname -m).sh`，其他平台参考 https://conda-forge.org/download |
| Agent 未出现在 Tab 列表 | 检查 agents 目录下对应 `.md` 文件的 YAML frontmatter 格式 |
| 环境信息未注入 | 检查控制台配置页 `IDA_PRO_HOME` 是否配置；查日志 `~/bw-security-analysis/logs/plugin_debug.log` 的 system.transform 段 |
| 虚拟环境损坏 | 删除 `~/bw-security-analysis/.venv`，重新运行 `install.sh` 重建 |
