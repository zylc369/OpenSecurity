# 【有趣的技术3分钟】一道 6000 位数字的题，死于 1990 年的攻击

> 本文含现役比赛（COMPFEST 18，2026-08-31 00:00 UTC 结束）的解法与 flag。**

> 看到一道密码学题，屏幕上吐出一个 **6152 位十进制**的公钥 e——第一反应是：这题是不是要算到宇宙热寂？
>
> 第二反应是：等等，1990 年就有人写过怎么杀这种题。

今天这道题来自印尼的 COMPFEST 18 CTF，名字特别友好，叫 **hello**。但它给你的见面礼一点也不友好：连上服务器，三行数据——

```
N = 1386014675526991533121346235991468658389553130033192669834035...（617 位）
e = 2136712867699397006037762861660083654575979527507561069263191...（6152 位）
c = 1550486281540729950781214286843052747305688053008172308393672...*t^9 + ...
```

N 是 RSA 模数，2048 比特，正常。e 是公钥指数，**20440 比特**——标准 RSA 里它就 65537，17 位。而密文 c 更奇怪：它不是一个大整数，是一个 **t 的九次多项式**。

三个数字，每一个都在暗示：这道题的 RSA，不太对劲。

---

## 第一幕：RSA，但是搬进多项式的世界

先用 30 秒复习标准 RSA：选两个大素数 p、q，令 N = pq。算出 φ = (p-1)(q-1)，选公钥 e、私钥 d，满足 **e·d ≡ 1 (mod φ)**。加密是 m^e mod N，解密是 c^d mod N——完事。

这道题改了两个地方。

**改动一：明文不是整数，是多项式。** flag 被切成 10 块，每一块转成整数，充当系数——明文变成了一个十项式：

```
m(x) = m₀ + m₁·x + m₂·x² + ... + m₉·x⁹
```

加密就是给这个多项式做 e 次幂：c(x) = m(x)^e。这就是密文长成 `...*t^9 + ...` 的原因。

**改动二：幂运算发生在一个"折叠世界"里。** 想象时钟算术：13 点就是 1 点，因为超过 12 就折回去。这道题的世界规则是 **x¹⁰ = 2**——任何多项式一旦算出 x 的 10 次方，就立刻折叠成常数 2。用密码学黑话说，这叫商环 Z_N[x]/(x¹⁰-2)；用人话说，这是一个自带的物理定律的小宇宙。

在这个宇宙里，"φ"也换了定义：**φ = (p¹⁰-1)(q¹⁰-1)**。

看起来面目全非。但接下来你会看到，它换的只是皮。

---

## 第二幕：1990 年的Wiener 攻击

这道题的私钥生成方式翻译成人话是：**出题人把私钥 d 造得很小**——刻意压在某个数学界限之下（为了"性能"或"好看"，现实世界里工程师们也真这么干过）。而 e 和 d 满足 e·d ≡ -1 (mod φ)，也就是：

**e·d + 1 = k·φ**（k 是某个整数）

现在做一个小学除法：两边同除以 d·φ：

```
e/φ = k/d − 1/(d·φ)   ≈   k/d
```

翻译一下：**e 和 φ 都是六千位的庞然大物，但它们的比值背后，藏着一个分子分母都很小的分数 k/d**——因为 d 被造小了，而 k 比 d 还小。

怎么把藏在大数里的"简单分数"挖出来？这正是**连分数**（continued fraction）的独门绝技。你其实早就见过它：祖冲之的密率 **355/113**，就是 π 的连分数展开里跳出来的最优近似——π 是个无限不循环的无理数，但它内部藏着一系列越来越精确的"简单分数"，连分数能把它们一个个按顺序吐出来。

1990 年，Michael Wiener 证明了：标准 RSA 里只要私钥 **d < N^0.25**，对 e/N 做连分数展开，k/d 必然出现在收敛子列表里——你挨个验过去，私钥就到手了。这是 RSA 历史上最著名的教训之一：**公钥越大，往往意味着私钥越小，而小私钥是致命伤**。

---

## 第三幕：换个变量名，攻击照用

那这道"多项式世界"的变体呢？

看两个替换：Wiener 用 e/N 做连分数，是因为 φ ≈ N（两者只差 p+q，相对误差小到可以忽略）。这道题里 φ = N¹⁰ + 1 − (p¹⁰+q¹⁰)，而 p¹⁰+q¹⁰ 相对 N¹⁰ 同样小到可以忽略——所以：

> **把 N 换成 N¹⁰，把 p+q 换成 p¹⁰+q¹⁰，1990 年的攻击原封不动搬进来。**

连分数吐出一串候选 (k, d)，然后是同样重要的另一半：**验证**。对每个候选，算 φ = (e·d+1)/k，再看 p¹⁰ 和 q¹⁰——它们的和是 s = N¹⁰+1−φ，积是 N¹⁰，正好是一元二次方程 z² − s·z + N¹⁰ = 0 的两个根。判别式是完全平方数、根恰好是整数的十次方、p 还能整除 N——全部命中，才是真私钥。

顺便坦白一个我自己的笑话：动手前我盯着题给的那些参数界，推演了小半个钟头"纯连分数在这个变体上数学上是否保证成立"，越推越玄。后来想起一条铁律——**便宜的实验先跑**。连分数脚本跑完：

```
[+] STAGE A HIT in 0.2s
```

0.2 秒。半小时的理论推演，输给 0.2 秒的实验。这本身也是一堂工程课。

---

## 第四幕（彩蛋）：解出密钥，解密却吐乱码

故事到这该结束了？没有。拿到 p、q、φ、d 之后，老老实实算 c^(φ−d)，解出来的不是 flag，是**乱码**——而且不是偶然，实测大约三成概率翻车。

原因回到那个"折叠世界"的物理定律。解密能成立，靠的是"转 φ 圈一切归位"——模运算世界里，幂指数本质是转圈数。但 **φ = (p¹⁰-1)(q¹⁰-1) 根本不是这个环的"真圈数"**：x¹⁰-2 在 mod p 的世界里怎么碎裂，决定了真正的圈数，而碎块的次数**不保证整除 10**（比如 mod 3 时，x¹⁰-2 碎成 2 次和 8 次两块——8 可不整除 10）。碎块的圈数没有整除进 φ，幂次就差了拍，解密直接走音。

修法倒不难，只是要虔诚：分别在 mod p 和 mod q 的世界里分解 x¹⁰-2，老老实实算出各自的真圈数 λ，用 e 的逆元做幂，再把两边的结果用 CRT 缝合回去。最后一步必须**重加密校验**——把解出的明文再加密一次，确认等于密文 c，才算闭环。密码学不相信"差不多了"。

---

## 结尾：换皮不换魂

flag 解出来是：

```
COMPFEST18{c0ngr4tzzz_h3ngk3rrrr_g3n3r4l1Zed_w13n3R_4ttacK}
```

翻译：**"恭喜你，黑客——广义 Wiener 攻击。"** 出题人在 flag 里跟你击掌，他出这道题就是为了等一个认出老朋友的人。

两件事值得带走。

**第一，密码学的攻击从不看结构的新旧，只看参数的弱点。** 这道题用了多项式、商环、折叠世界，看起来 2026 年得很；但私钥 d 一小，1990 年的攻击换个变量名照杀。这就是为什么真实世界的 RSA 实现规范反复死磕那些"无聊"的条款——私钥必须用密码学随机数生成、必须足够长、两个素数绝不能复用。**结构再新颖，参数踩进射程，祖传攻击一发入魂。**

**第二，便宜实验先跑。** 半小时的最坏情况推演，不如 0.2 秒的验证脚本。理论负责解释世界，实验负责裁决方向——顺序别反。

毕竟，在密码学的世界里，能让 2026 年的题目轰然倒下的攻击，诞生于 1990 年。

老酒从不退场，只是换了瓶子。
