# 【有趣的技术3分钟】一道禁了句号的题，死于数字 46

> 本文素材来自进行中的 PwnSec CTF 2026。

> 这道题的防御，密得像一份海关禁运清单：句号、"flag" 这个词、还有一整类危险指令，统统不许入境。
>
> 而我最后的通关文书里，一个违禁品都没有——那个句号，是入境之后现场用数字拼出来的。

先交代背景：CTF，一种黑客比赛。主办方在网上部署一批故意留了漏洞的系统，选手负责攻破；每攻破一个，就能挖出一串通关暗号，叫 flag。

这次的靶子是个很小的网站，只干一件事：你交给它一段数据，它替你"解开"——把这段数据还原成 Python 里的活对象。用的还原工具是 Python 的祖传格式 pickle：一种"罐头"技术，能把对象压成字节条存放，需要时再照着一份指令清单原样吹起来。

麻烦在于，"吹起来"的过程是照着指令干活的——理论上，恶意指令能让它在服务器上随便做事。出题人显然知道这一点，上了**三层防御**：

第一层，字符禁运：句号、还有 os、system、flag 等十一个敏感词，数据的任何一个角落都不许出现。第二层，指令审查：最危险的那类"调用指令"被点名拉黑。第三层最狠，白名单：还原器只许使用两个模块里的工具，其余一律拒绝加载。

看起来滴水不漏。但 Python 有一个祖传设计，把后门开在了正门上。

---

## 第一幕：最顺手的指令被禁了

"让服务器替我干活"的标准姿势，是往罐头里塞一条调用指令：见到某个函数，配上参数，执行。

这类指令的名字叫 REDUCE——现在它被点名拉黑了。

但 pickle 的指令清单是一份几十年的老手册，同一个工位往往有两个名字。翻到隔壁页，有一条叫 OBJ 的指令：活儿一模一样，只是名字里没有那四个字母。指令审查扫的是名字，不认语义。

第一层同样经不起推敲：禁运的是"字符"，不是"意思"。就像海关把字母 Q 列入禁运，你照样可以让人带一块写字板进去，现场画出 Q 来。句号怎么拼，后面再说。

---

## 第二幕：白名单锁死了门，钥匙串缝在窗帘后

真正的墙是第三层。两个被放行的模块里，没有任何能读文件、能执行命令的工具——白名单拦的不是"你带没带违禁品"，是"你这个人根本不许进门"。

我先抄了近路，去翻这两个模块的口袋，找它内部引用的别的工具——第一版就翻车：我引用的那个内部名字，在服务器这个版本的 Python（3.12）里根本不存在。第二版又翻车：我拿"按名字取属性"的扳手当"按编号取格子"的用，程序报错"模块不可下标"。

第三版，摸到了窗帘。

Python 有个很少被提起的惯例：**每个模块身上都挂着一个叫 `__builtins__` 的属性，它就是整本内置工具箱的字典**——open（打开文件）、print（打印）……全在里面。白名单检查的是"你从哪个门进"；而放行名单里的 collections 是个守规矩的老部门，它办公室的窗帘后面，缝着全公司共用的那串万能钥匙。

门禁查工牌，不搜窗帘。

---

## 第三幕：两个句号，一个不写

工具箱到手，只剩最后一件事：告诉服务器去读 `/app/flag.txt`。

问题回到了禁运清单：这个路径里有一个句号。而 pickle 的字符串，必须原样写进数据。

但老手册里有条不起眼的规定：**整数可以用"人类数字"来写**。你想表达 46，就在数据里写下字符"4"和字符"6"——字节流里是两个再普通不过的数字字符，没有那个被禁运的字节。至于"46 就是句号"这件事，是入境之后由服务器自己换算的。

于是我把整条路径拆成十三个数字（47 是斜杠，97 是字母 a……46 是那个句号），排成清单塞进罐头，让服务器照单拼装。

还有一个意外之喜。罐头的末尾按规矩要盖一个"完"字章——这个章的字节真身，**恰好也是句号**。盖不了？那就不盖。还原器读完这份没有句号的数据，一头雾水地抛出"数据被截断"的报错——而网站的代码里早写好了"出错就吞掉"。报错被咽下的那一刻，前面的十三步连招已经全部执行完毕。

（彩蛋：那道"禁 REDUCE"的安检，用的审查工具读到"没写完"的数据会当场死机。网站的安检代码在表格里填了个 "Error!"——然后正常放行。第二层防御，就这么绕着绕着把自己也绕了进去。）

---

## 尾声：五版罐头，205 个字节

从第一版翻车到最终命中，前后一共写了五版，最终成品 205 个字节，十三步连招：取工具箱、拼路径、开文件、把内容打印出来。

老规矩，先拿题目附件在本地把整套环境跑通验证，再对线上出手——一发命中：

```
pwnsec{444e492f7eb33861}
```

这道题叫 **pickle**，PwnSec CTF 2026 的 web 分类，难度 Easy——我打开页面时它值 188 分，已有 36 支队伍解出。

---

## 结尾：带走两条

**第一，黑名单禁得住拼写，禁不住语义。** 字符可以拼、指令可以换同义词、报错可以被吞——"写法"层面的封锁，通道数不清。真正硬的防线要拦"能力"本身：这个进程到底有没有权利读文件，而不是数据里有没有出现某个词。

**第二，白名单放行的是门，没搜的是口袋。** 你放行了一个模块，就连带放行了它运行时携带的一切隐含引用——窗帘后的钥匙串只是其中一串。写白名单时多问一句：每个被放行的对象，口袋里还装着什么？

海关禁得住句号，禁不住 46。
