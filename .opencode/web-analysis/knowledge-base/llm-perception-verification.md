# LLM 感知结果交叉验证（OCR/ASR 防幻觉协议）

## 适用场景

任何将 vision-LLM OCR（如 glm-ocr MCP）或 ASR（whisper 等）输出作为**分析结论依据**的时刻。vision-LLM 会产生"场景级合理文本幻觉"：从整图场景先验编造出看似合理、可自洽复现、反相稳定的内容——一致性不能证明真实。

## 幻觉签名（满足任两条即高度可疑，三条齐=判定幻觉）

1. **双经典引擎零检出**：tesseract 与 RapidOCR（或第二套传统引擎）在全图及增强裁剪上均无任何检出。真实文字至少被一个引擎部分命中。
2. **裁剪失效**：把画面任意象限/瓦片裁出（含 2-3x 放大增强）后 LLM 读不出该内容，只有完整原图能读出。真实文本总在某个裁剪里可见；幻觉依赖整图场景上下文。
3. **位置追问矛盾**：追问"内容在画面什么位置"，得到的答案与像素级渲染（高通滤波 ASCII 渲染法）不符，或多次询问位置漂移。

## 强制流程（未完成不得将 LLM 感知结果写进结论）

1. LLM OCR 得到文本 T → 立即用两个经典引擎对原图 + 对 T 所在区域增强裁剪各跑一遍。
2. 任一经典引擎命中 T（或其主要字符）→ 通过，可采用。
3. 两者零命中 → 执行"像素定位"：对 T 所在区域做高通滤波 ASCII 渲染（9-21px 均值滤波，2-6px 采样），人工检查是否存在对应字形结构。
4. 字形存在但引擎读不出 → 对比度增强（autocontrast/gamma）后重试步骤 1；字形不存在 → **判定幻觉，弃用 T**。
5. 判定幻觉后必须归档（结论+证据），防止后续轮次重复采信。

## 像素终裁法（判定"文本变化"的真伪）

声称"文本 A 变成文本 B"时，对前后两帧做逐像素差异图：
- 真实变化 → 差异图中出现字形形状的局部差异簇（数字/字母笔画轮廓）
- 无字形差异簇（仅全局亮度渐变、边缘移动、噪声）→ "变化"是对比度跨越 LLM 判读阈值产生的伪翻转
- 辅助判据：低对比度过渡期的 LLM 读数若在同一位上随机摇摆（如 3/8 交替），即为伪翻转特征

## ASR 专项规则

1. 模型选择：结论性转写必须用本地最强模型（如 large-v3）；base/small 仅作快速预筛，其输出不得作为依据。
2. **空输出 ≠ 漏检**：大模型返回空/无段落，而小模型有"输出"时，优先怀疑小模型幻觉。已知名单：对音乐/纯伴奏，小模型常幻觉 "Thanks for watching"、字幕样式文本、百分比播报。
3. 音乐判别：转写失败时先做频谱分析——连续谐波结构（基频+泛音列随时间平滑移动）= 音乐/非语音，语音则呈共振峰结构与音节节奏。
4. 倒放检验：可疑"语音"反转后重转写（经典隐写手法）；两向皆空+音乐频谱 → 关闭音频方向。

## 成功/失败判据

- 流程通过（引擎命中或字形实证）→ 文本可采用，标注验证方式
- 流程判定幻觉 → 该文本从候选中永久移除并记录证据链
- 案例自测：低对比度监控视频帧上 LLM 稳定读出 7 位数字，双引擎全图/裁剪零检出、消融失效、差异图无字形簇 → 按本协议判幻觉并关闭该线索
