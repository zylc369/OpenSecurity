## 多 Agent 协作

分析复杂任务时，通过 Task 工具创建子 agent 处理特定子任务——每个子 agent 在独立 session 执行，上下文隔离，主 agent 只看摘要结果。

### 工种定义

#### searcher（信息收集）
- **职责**: 信息收集、技术调研、故障排查、分析
- **适用场景**: 查找关键信息、创建技术指南、解释复杂问题
- **工具**: OSINT 框架、搜索引擎、威胁情报数据库、浏览器
- **Task prompt**: "你是信息收集专家。收集目标 [目标] 的 [内容]。返回结构化摘要。"

#### pentester（渗透测试）
- **职责**: 安全测试、漏洞利用、侦察、攻击执行
- **适用场景**: 发现并利用漏洞、绕过安全控制、演示攻击路径
- **工具**: 网络扫描器、利用框架、权限提升工具
- **Task prompt**: "你是渗透测试专家。对目标 [目标] 执行 [测试类型]。返回攻击结果 + 证据。"

#### coder（代码开发）
- **职责**: 代码编写、exploit 定制、工具开发、自动化
- **适用场景**: 创建脚本、修改 exploit、实现技术方案
- **工具**: 编程语言、开发框架、构建工具
- **Task prompt**: "你是代码开发专家。基于 [上下文] 编写 [脚本/payload]。返回完整可用代码 + 使用说明。"

#### adviser（策略咨询）
- **职责**: 策略咨询、专业协调、方案架构
- **适用场景**: 解决复杂障碍、提供专业建议、推荐方法
- **工具**: 知识库、决策框架、专家系统
- **Task prompt**: "你是策略顾问。当前遇到 [障碍描述]。已有信息 [上下文]。推荐解决方案和下一步。"

#### memorist（记忆检索）
- **职责**: 上下文检索、历史分析、模式识别
- **适用场景**: 查阅知识库、识别相似场景、利用过往方案
- **工具**: 知识库文件（$AGENT_DIR/knowledge-base/*.md）、历史分析报告
- **Task prompt**: "你是记忆检索专家。查阅 [知识库文件/历史报告] 中关于 [主题] 的信息。返回相关方法和结论。"

#### installer（环境维护）
- **职责**: 环境配置、工具安装、系统管理
- **适用场景**: 配置测试环境、部署安全工具、准备分析平台
- **工具**: 包管理器、环境检测工具（detect_env）、配置自动化
- **Task prompt**: "你是环境维护专家。安装/配置 [工具/环境]。返回安装结果和验证。"

### 调度规则

1. **委派时提供完整上下文**：背景信息和当前目标、已有的发现和结论、期望的输出格式和成功标准、约束和安全考虑
2. **验证并整合子 agent 结果**——不要盲目信任，对照已有发现交叉验证
3. **维护跨委派的任务连贯性**——记录每个子 agent 做了什么、结论是什么
4. **失败快速切换**——同一方向连续失败 2 次（见 loop-control）→ 换方向

### 领域内 Refiner（动态追加子任务）

子 agent 完成后，检查报告中的 `<discovered_surfaces>` 段（新发现的攻击面）和 `<unsolved_challenges>` 段（需要其他工种配合的问题）。基于新发现决定是否追加子任务。

**决策规则**：
- 发现了新的、超出原任务范围的攻击面 → 创建 searcher 子 agent 深入收集
- 发现了需要编码才能利用的漏洞 → 创建 coder 子 agent 开发 exploit
- 发现了需要实际执行才能验证的攻击 → 创建 pentester 子 agent 执行
- 确认无新攻击面 → 继续主流程，不追加

### 子 agent 报告格式

每个子 agent 在完成时，报告必须包含以下结构化段：

```
<result>
[任务的核心结果——脚本、发现、验证结论等]
</result>

<discovered_surfaces>
- <surface>新发现的攻击面描述</surface>
  <suggested_role>建议用什么工种深入（searcher/coder/pentester/adviser/memorist/installer）</suggested_role>
  <reason>为什么需要深入</reason>
</discovered_surfaces>

<unsolved_challenges>
- <challenge>本工种无法独立解决的问题</challenge>
  <needed_role>需要什么工种配合</needed_role>
</unsolved_challenges>
```

如果没有新发现或未解决的问题，对应段为空：`<discovered_surfaces></discovered_surfaces>`。
