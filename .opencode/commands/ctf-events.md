## 角色与目标

快速展示近期 CTF 比赛，分「进行中」「即将开始」两个表格，帮助快速决定参加哪场。

## 执行

运行配套脚本拉取并格式化（仅依赖 Python 标准库）：

```bash
$PYTHON_CMD "$OPENCODE_ROOT/commands/ctf_events_lib/ctf_events.py"
```

## 输出处理

- 脚本标准输出已是两个 markdown 表格，**原样呈现给用户**，不要改写格式或自行补充/编造数据。
- 脚本若报错（网络/API 故障，错误信息在 stderr），**如实告知失败原因**，不臆造比赛数据。

## 规则说明（脚本内置，无需手动干预）

| 维度 | 规则 |
|------|------|
| 数据源 | CTFtime 官方 API |
| 窗口 | 过去 7 天 ~ 未来 30 天 |
| 进行中排序 | 剩余时间降序（剩余多的在前） |
| 即将开始排序 | 开赛时间升序（最近在前），权重 ≥ 30 标 ⭐ |
| 现场过滤 | 即将开始仅线上；进行中保留全部（含现场，带「线上/现场」列） |
| 非典型过滤 | 持续 > 14 天视为练习平台/长期 challenge，剔除 |
| 时区 | 开赛时间显示本地时区，表头已标注 |
