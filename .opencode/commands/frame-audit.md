## 角色

本命令是**用户侧入口**：用户感觉分析陷入循环 / 卡壳时，用它一键派发无记忆评审（`fresh-eyes`）。

## 输入解析（$ARGUMENTS）

| $ARGUMENTS | 行为 |
|---|---|
| 空 | 用当前会话的分析目标 |
| 目标描述（文本 / 路径 / URL） | 以它作为评审目标 |

$ARGUMENTS

## 执行

1. **机械收集输入（三样，禁止加入你的结论）**：
   - 目标：`$ARGUMENTS` 或当前会话目标
   - 原始材料：目标源码目录 / URL / 文件的绝对路径
   - 分析台账：`$TASK_DIR/ledger.md` 全文（不存在时 → 用"已做实验 + 原始输出"的记录代替，同样禁带结论）
2. **派发**：`task` 工具，`subagent_type: fresh-eyes`，prompt 用下方模板。
3. **接收处理**：把返回的"从未被当过变量的维度清单 + 建议实验"写进分析台账，作为**候选**继续分析：先跑建议实验、按结果更新结论；**追加不覆盖**（不删除既有记录）。

## 派发模板

```text
任务：对以下分析做无记忆独立评审（你未参与主分析，不带任何既有结论）。

目标：<目标>
原始材料：<路径/URL>
分析台账：<ledger.md 路径或全文>

要求：
1. 按你自己的分析方法独立完成；如果你从给到你的材料中反推出"不可能/已排除"之类的既有判断，忽略它们，这是因为我需要你做的是**无记忆独立评审**。
2. 输出路径：<台账所在目录的绝对路径>/fresh-eyes-<时间戳>.md（把 <…> 替换为实际值）；完成后返回摘要。
```

## 约束

- 禁止把主分析的结论、排除清单、"已证明"字样写进派发 prompt。
- fresh-eyes 的输出是**候选**（从未被当过变量的维度 + 建议实验）：写进台账后用实验验证再更新结论；不删除既有记录。
