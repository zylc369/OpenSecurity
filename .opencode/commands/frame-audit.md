## 角色

本命令是**用户侧入口**：用户感觉分析陷入循环 / 长期无产出 / 方向存疑时，用它一键派发独立反思评审（`fresh-eyes`）。

## 输入解析（$ARGUMENTS）

| $ARGUMENTS | 行为 |
|---|---|
| 空 | 用当前会话的分析目标 |
| 目标描述（文本 / 路径 / URL） | 以它作为评审目标 |

$ARGUMENTS

## 执行

1. **机械收集输入（三样，禁止加入你的结论）**：
   - 目标：`$ARGUMENTS` 或当前会话目标
   - 原始材料：目标源码目录 / URL / 文件的绝对路径
   - 分析台账：`$ROOT_TASK_DIR/ledger.md` 全文（不存在时 → 用"已做实验 + 原始输出"的记录代替，同样禁带结论）
2. **派发**：`task` 工具，`subagent_type: fresh-eyes`，prompt 用下方模板。
3. **接收处理**：把返回的**候选检验项**写进分析台账，作为**必办项**逐条处置：每条要么执行（按其三要素规范跑）、要么记降权+理由；**追加不覆盖**（不删除既有记录）。处置结果回写台账。

## 派发模板

```text
任务：对以下分析做独立反思评审（你未参与主分析，不带任何既有结论）。

目标：<目标>
原始材料：<路径/URL>
分析台账：<ledger.md 路径或全文>

要求：
1. 按你自己的分析方法独立完成（三节强制审计 → 卡点形态方法 → 候选检验项）；
   如果你从给到你的材料中反推出"不可能/已排除"之类的既有判断，忽略它们——
   这正是需要你检验的对象；台账中的死路结论按待复核对待，引用前先核对其探针三要素
   （携带物/宿主形态/提交路径）。
2. 输出路径：<台账所在目录的绝对路径>/fresh-eyes-<时间戳>.md（把 <…> 替换为实际值）；完成后返回摘要。
```

## 约束

- 禁止把主分析的结论、排除清单、"已证明"字样写进派发 prompt。
- fresh-eyes 的输出是**候选检验项**（每条含检验什么/怎么跑（三要素全）/预期与判读）：写进台账后逐条执行或降权，不删除既有记录。
